# Faza 4 — Aplikacja mobilna Flutter

**Cel:** Zbudować aplikację na Androida, która zastępuje Excel przy wprowadzaniu wyników treningów.

**Zakres:** ~4–6 tygodni  
**Status:** 🔲 Nie rozpoczęta — zacznij po ukończeniu Fazy 3

---

## Czego się nauczysz
- Podstawy Dart (składnia, typy, funkcje, klasy)
- Widgety Flutter — budowanie UI
- Nawigacja między ekranami
- State management (podstawowy)
- HTTP calls do backendu FastAPI

## Co zbudujesz
Aplikacja mobilna z ekranami:
- **Wybór treningu** — PUSH / PULL / NOGI
- **Ekran ćwiczeń** — lista ćwiczeń z aktualnego planu
- **Logowanie serii** — wpisanie ciężaru, powt., RIR dla każdej serii
- **Historia** — poprzednie sesje i postęp ciężarów

## Deliverable
Aplikacja działająca na telefonie Android, komunikująca się z lokalnym backendem.
